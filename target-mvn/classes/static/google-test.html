💡 Cách sử dụng để test API:

  1. Bấm nút Sign in with Google ở trên và đăng nhập bằng tài khoản Google của bạn.
  2. Sau khi đăng nhập thành công, mã ID Token sẽ hiển thị trực tiếp trên màn hình.
  3. Nhấp vào nút Sao chép để copy mã token này.
  4. Mở Swagger UI, chọn API /api/auth/google, dán mã Token này vào trường idToken và chạy (Execute) để kiểm thử!
