How it works

A clear learning flow from preparation to performance.

01

Lecturers create learning spaces

Organize classes, members, roadmaps, learning nodes, and resources by topic.

02

Students join with invite codes

Students enter the correct learning space and immediately see what to prepare.

03

Students prepare at home

Watch videos, read documents, review code examples, and complete short quizzes before class.

04

Class time becomes active

Prepared students use class time for discussion, practice, feedback, and deeper problem solving.

Platform features

Everything needed to run a flipped classroom in one place.

LS

Learning Spaces

Manage classes, mentors, students, roles, and participation status.

RM

Roadmaps

Design ordered learning paths with nodes, resources, and checkpoints.

DOC

Course Materials

Attach videos, PDFs, websites, GitHub links, and reference material to each node.

QZ

Quizzes

Create assessments, track attempts, and understand student readiness before class.

Roles

Designed for both lecturers and students.

LC

Lecturer

  • Create structured learning spaces and course roadmaps.
  • Publish resources and quizzes for preparation.
  • Review progress and identify students who need support.
ST

Student

  • Join courses quickly using invite codes.
  • Follow roadmap nodes and access all learning materials.
  • Complete quizzes and receive reminders for pending work.
