Frontend Structure

FlippedClass dang dung Spring Boot MVC va Thymeleaf lam UI delivery path duy nhat. Khong can React, Vite, SPA root hay Node package de chay giao dien.

Runtime model

  • TemplateController map URL trinh duyet toi Thymeleaf view.
  • templates/ chua HTML Thymeleaf.
  • static/assets/ chua CSS, JS, image, font va manifest.
  • Du lieu dong co the render bang model Thymeleaf hoac goi REST API qua fetch().

Main routes

  • / -> landing page.
  • /login va /signin -> trang dang nhap.
  • /register va /signup -> trang dang ky.
  • /student/dashboard -> dashboard sinh vien.
  • /lecturer/quizzes -> quan ly quiz cua giang vien.

Rule

Them giao dien moi bang Thymeleaf template va static asset. Khong them SPA entry point vao root project.
